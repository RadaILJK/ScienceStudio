# Классификация фокальной дистонии по данным МРТ

Исследовательский проект по классификации участников с фокальной дистонией верхней конечности (ULD) и здоровых участников (HC) по T1-взвешенным МРТ.

Студент: Лихачева Рада  
Научный руководитель: Андрей Сомов

## Метод и результаты

В качестве базового подхода используются признаки замороженного энкодера BrainIAC и логистическая регрессия. Выборка — 66 участников: 29 ULD и 37 HC. Оценка проводится с помощью стратифицированной кросс-валидации на 5 фолдах.

| Метрика | Значение |
|---|---|
| Accuracy | 0,576 |
| Balanced accuracy | 0,562 |
| ROC-AUC | 0,569 |

Результаты предварительные. Дообучение энкодера — следующий этап работы.

## Запуск

Команды выполняются из корня проекта. Версии библиотек указаны в `code/requirements_observed.txt`.

Данные — [OpenNeuro ds006395](https://openneuro.org/datasets/ds006395). Исходные МРТ в репозиторий не включены. Перед запуском нужно скачать данные и указать пути в `code/config.json`.

Проверка входных данных и запуск эксперимента:

    python code/run_baseline.py --check-inputs
    python code/run_baseline.py

Запуск на готовых признаках без повторной обработки МРТ:

    python code/run_baseline.py --embeddings path/to/embeddings.npz

Новые результаты сохраняются в `results/runs/`. Исходные результаты в `results/metrics.json` не перезаписываются.

Построение рисунков и обновление таблиц статьи:

    python code/plot_results.py
    python code/build_report.py

Тесты:

    python -m unittest discover -s code/tests -v

## Сборка статьи

Статья собирается в Overleaf. Компилятор — pdfLaTeX, главный документ — `article/article.tex`.

Таблицы и библиография уже включены в проект. Запускать Python для сборки PDF не требуется.

## Ограничения

Полное повторение эксперимента требует МРТ и весов BrainIAC. Исходные OOF-предсказания не сохранены: историческая ROC-кривая приложена как изображение из ноутбука.
